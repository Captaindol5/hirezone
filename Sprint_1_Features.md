# Sprint 1 Scope and Features

## 1. Features (Current Scope)
1. **Authentication and Role-Based Portal Routing**
   - Secure login via Firebase Authentication.
   - Dynamic routing to tailored dashboards based on user roles (HR, Interviewer, Manager).
2. **AI-Powered Resume Screening & Bias Guardrails**
   - Automated PDF resume parsing.
   - AI-driven candidate evaluation against job requirements.
   - Built-in bias guardrails to anonymize personally identifiable information (PII).
3. **Job Applications & Careers Page**
   - Public-facing careers page listing open roles.
   - Seamless application process feeding directly into the HR pipeline.
4. **Real-time Notifications**
   - In-app notification bell.
   - Real-time updates for key events (e.g., new application submissions, screening completion).
5. **Custom Pipelines**
   - Allow HR users to configure custom hiring pipelines and define interview stages tailored to each open position.
6. **Interactive Kanban Board and Stage-Gate Enforcement**
   - Provide a visual Kanban-style board for tracking candidates through the recruitment pipeline from application to hiring or rejection.
7. **Feedback Portal and Scorecard Submission**
   - Provide a structured interviewer feedback portal for submitting standardized candidate evaluations.
8. **Executive Analytics and Candidate Comparison Matrix**
   - Detailed analytics and a matrix for comparing candidate performances.

## 2. Removed / Deprecated Features from Initial Plan
The following feature from the initial project plan has been removed in the current Sprint 1 scope:
- **Candidate Portal**: *Candidates will not have a dedicated post-application portal in this sprint.*

## 3. Exclusions in Sprint 1
- Any advanced recruitment features not described within the current project plan.
- Recruitment features beyond those of the described role-based recruitment process.
- Other integrations or services apart from those described within the current project plan.
- Future developments that might arise after the system deployment and evaluation.

## 4. Deliverables in Sprint 1
- Web Application Framework of Role-Based Recruitment and Hiring Tracker.
- Positions Management Module (Careers Page).
- Candidates’ Tracking Board (Interactive Kanban).
- Interviewer Evaluating System (Feedback Portal).
- AI-Powered Screening Module with Bias Guardrails.
- Workflow Restriction through Mandatory Interviewer Feedback & Role-Based Access Control.
- Analytics and Reporting Engine (Executive Analytics).
- System Models and UI Designs.
